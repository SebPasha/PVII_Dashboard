# PV2 dashboard, the end-user page

The two-tab reading of the PV2 work: Regional and Country explorer, for someone
reading the result rather than producing it. Built by
`python3 -m pv2.dashboard.dashboard --variant min` in Environment_UNDP and copied
here whole; do not edit index.html by hand, rebuild it.

The four-tab working page, the monitoring app and the registers are published
separately at AI_Unveils_Tomorrow and are not affected by anything here.
